# Phase 6

ロールと、管理者向けの公式問題編集。カスタム部屋・ユーザー投稿問題は対象外。

## ロール

| ロール | どこ | できること |
| --- | --- | --- |
| ゲスト | 未ログイン | 一人練習。成績は localStorage のみ |
| 一般 (`user`) | ログインユーザーの既定 | 成績をサーバーへ保存 |
| 管理者 (`admin`) | seed した管理者 | 公式問題の編集画面 |

ゲストは DB 行を持たない。サインアップした人は必ず `user`。`role` はクライアントから変更できない。

## 管理者アカウント

`pnpm db:seed` がローカル用管理者を作る（または更新する）。

- 名前: Administer
- ID: admin
- メール: admin@qwyzm.com

パスワードは seed 実装を見る。本番では変える。

## 公式問題エディタ

- 管理者だけ `GET/POST/PUT /api/admin/questions`
- 本文、想定解（表示解＋入力解、必須1つ）、別称（任意・複数）、判定のみ（想定解/別称の下、入力解のみ）、惜しい解答（入力解のみ）、ジャンル、公式 / 下書き
- 下書きは一人練習の出題に出ない

## まだやらない

- 問題削除（ソフトデリート UI）
- 出典・難易度の本運用
- ユーザー問題
- 保存失敗の通知、履歴画面、レーダー実データ
