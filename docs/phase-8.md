# Phase 8

共有 RuleSet、ホームランチャー、設定画面。カスタム部屋・WebRTC / 権威 WS・問題セット実体は対象外。

## 目的

一人練習と対戦が共有する単一の設定スキーマ（RuleSet）を確定し、ホームから 4 系統へ遷移する骨格と設定画面を作る。キーバインドと文字送り速度を「定数固定」から「設定が実際に効く」状態にする。

## 含むもの

1. `RuleSet` / `UserSettings` 型、zod スキーマ、既定値、壊れた JSON からの migration
2. ホームランチャー（一人練習 / カスタム部屋（未実装表示）/ 履歴 / 設定）
3. 設定画面（キーバインド、文字送り速度、音量枠＝値保持のみ）
4. キーと速度の実効化。設定は `qwyzm.settings.v1`（成績キーとは別名）
5. `ruleSetToEngineSettings`。FSM と未実装誤答ルールは触らない

## 含まないもの

- 新しい誤答ルールや出題戦略（Phase 9）
- 問題セット CRUD（Phase 10）。`questionSetId` は null の枠だけ
- 対戦 / WS / 部屋コード（Phase 11）
- 設定のサーバー同期
- CSS・アニメ・SE の作り込み

## 完了条件

- ホームから一人練習・履歴・設定に到達でき、カスタム部屋は明示的 disabled
- 一人練習フォームと設定画面が同一の RuleSet 型を読み書きし、リロード後も保持
- Space ハードコードと速度 normal 固定が除去され、設定が実挙動に効く
- 既存成績（`qwyzm.play-data.v1`）が消えず表示できる
- lint / typecheck / test / build が緑
