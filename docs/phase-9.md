# Phase 9

game-core の誤答ルール完成と直近回避出題。対戦通信・問題セット CRUD は対象外。

## 目的

`WrongAnswerRule` 4 種を型だけから実装に落とし、`RECENT_AVOID_N=100` を出題戦略に接続する。Phase 11–12 の対戦が規則面で待たされないようにする。

## 誤答ルール

全ルール共通: 誤答者は同一問題で再解答できない（ロック）。

| ルール | 動作 |
| --- | --- |
| `end_question` | 誤答で即問題終了（既存。一人練習デフォルト） |
| `resume_from_position` | 誤答者をロックし、未ロック者が残れば押下位置から本文再開（既存） |
| `no_one_else` | 誤答者をロック。本文は再開せず、未ロック者は同じ位置のまま早押し可 |
| `reread` | 誤答者をロックし、本文を先頭から読み直す。`maxRereads`（既定 1）を超えたら終了 |
| `next_fastest` | 同一問題の押下順キューの次の人だけに解答権。本文は再開しない。キューが尽きたら終了 |

1 人練習では 4 種とも実質 `end_question` に収束する（他者がいないため）。UI に注記を出す。

## 出題

`QuestionPickStrategy` が直近 `RECENT_AVOID_N` 問の questionId を除外する。候補が足りなければ除外を段階的に緩め、必ず要求数を返す。

## 含まないもの

- WS / 部屋 / 対戦通信
- 問題セット CRUD
- 設定キー名の変更
- UI の見た目作り込み

## 完了条件

- 4 種が engine で動き、人数 1/2/4 の決定論テストがある
- 設定と開始フォームから 4 種を選べ、実挙動に効く
- 直近回避が出題に効き、候補不足でも止まらない
- 既存設定・成績が壊れない
- lint / typecheck / test / build が緑
