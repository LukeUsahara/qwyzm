# Phase 2

一人練習ループの次。認証・対戦・WebRTC はまだ入れない。

## 目的

- 「全て」または単一・複数ジャンルで出題できる
- 問題ごとの成績をゲーム内で記録し、終了画面で見られる

問題データは引き続き `apps/web/src/fixtures/`。DB にはまだ載せない。

## 含むもの

1. 階層ジャンル（親を選ぶと子も対象）
2. 開始画面のジャンル選択。「全て」は本ジャンルの全葉が対象
3. `game-core` が 1 問ごとに play record を残す
   - 問題 ID、正誤、回答、押下時間、押下位置、押下順位、回答開始/確定時間
4. 終了画面で問ごとの結果一覧

## 含まないもの

- ログイン
- カスタムルーム / WebRTC
- 成績の DB 永続化
- レーダーの通算データ（枠は既存のまま）
- 読み上げ、ユーザー出題
