# Phase 7

履歴とプロフィールの実データ。カスタム部屋・WebRTC は対象外。

## 目的

蓄積した一人練習の成績を、終了画面以外でも見られるようにする。核は「早押しの練習・分析」なので、公式問題の次は対戦よりこちら。

## 含むもの

1. **履歴** — 過去の一人練習を一覧し、選んだゲームの分析（正誤、その問題の押下位置と自分の過去平均）を見返す
2. **プロフィール** — 左パネルのジャンル別正解率を、保存済み記録の本ジャンル根から描く
3. **保存失敗を出す** — ログイン中の `saveGame` が落ちたら終了画面で分かるようにする

押下位置の比較はこれまでどおり **問題ごと**。ジャンル横断の平均押下位置は出さない。未ログインは localStorage、ログイン中は API。混ぜない。

## API

`GET /api/games` に加え、`GET /api/games/:id` で自分の1ゲームを返す。

## 含まないもの

- カスタム部屋 / WebRTC / フレンド
- ユーザー投稿問題、問題の削除 UI
- ゲスト成績のアカウント移行
- 全ユーザー横断の平均押下位置
- 出典・難易度の本運用
