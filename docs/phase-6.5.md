# Phase 6.5

公式問題を 100 問に増やす。ゲーム規則・認証・対戦は触らない。

## 作問

競技早押しの定石に合わせる。

- 前フリ（あまり知られていない情報）を先に置き、後限定（有名な情報）を後ろに置く
- 答えが一つに定まること
- 音で聞いたときの同音異義を避ける
- 中学生以上。『ひらがなの最初は？』のような簡単すぎる問題は入れない
- 高校生クイズや競技クイズでよく出る人物・事件・作品・地理を厚めにする
- 文末は「〜でしょう？」

## カタログ

`packages/play-data/src/fixtures/questions.ts` が正本。`pnpm db:seed` で DB に書き込む。

簡単すぎた既存問（ひらがなの最初、水の化学式、円周率、人数、放送月など）は削除した。富士山・豚に真珠・紫式部・エベレストなどは前フリを付けて残している。
