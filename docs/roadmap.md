# v1 完成ロードマップ

2026-08-19。Claude Opus が全体像を承認し、実装は Cursor AI が担当する。UI のピクセル調整・アニメ・SE は最終フェーズで人間が行う。

詳細な画面仕様は既存の `docs/phase-*.md` と本ファイル。Phase 8 以降の実装計画は各 `docs/phase-N.md`。

## v1 完成の定義

1. ホームから一人練習・カスタム部屋・履歴/分析・設定の 4 系統に到達でき、全て実データで動く。
2. 部屋を作り部屋コード / URL で参加し、一人練習と同一の RuleSet（問数・ジャンル / 問題セット・得点・ペナルティ・誤答ルール・文字送り速度）で対戦が成立する。
3. game-core の誤答ルール 4 種と出題戦略・キーバインド・速度が全て実際に効く。
4. 対戦結果も履歴に残り、押下位置は questionId 単位のまま（横断平均しない）。
5. lint / typecheck / unit test / build が緑。見た目の作り込みは未着手でよい。

## Post-v1

フレンド、ユーザー投稿問題、TTS、難易度自動算出、ランダムマッチ、OAuth、ゲスト成績移行、誤答の自己分類、あと押し練習。v1 では部屋コード招待と公式問題で足りる。
