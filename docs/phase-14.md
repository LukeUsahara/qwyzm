# Phase 14

製品としての締め。到達不能な導線と壊れた空状態を消し、一人練習と部屋の smoke を通す。

## 目的

ホームから 4 系統が実データで動き、試合中に左ナビで進行が消えない。プレースホルダは撤去するか、仕様上の未対応と分かる文言にする。

## 含むもの

1. 空状態・読み込み・エラー・保存失敗の日本語表示（履歴、セット、部屋、レーダー、開始フォーム）
2. 部屋の signaling エラーコードを日本語にする
3. 試合中は左ナビとログイン操作を無効化する（ゲームオーバー後は解除）
4. フレンド枠は Post-v1 と明示する。音量は値保持のみと明示する
5. smoke E2E（練習 1 試合、部屋 1 試合）。未回答タイムアウトで終了まで進む
6. README / ADR / architecture / game-fsm / roadmap を現状に合わせる

## 含まないもの

新機能、ピクセル調整、SE、`/room/:code`、ランキング、フレンド実装。

## 完了条件

- lint / typecheck / unit test / build が緑
- `pnpm test:e2e` が緑
- 「未実装」が残るのは音量（Phase H）とフレンド（Post-v1）だけ
