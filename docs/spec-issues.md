# 仕様ギャップと確定事項

実装前に挙げた項目は、2026-08-17 の確認で次のとおり確定した。

## 入力と表示

- 入力はひらがな・英字・数字・長音「ー」のみ。カタカナ・漢字はバリデーションで拒否する
- 表示用の正解がカタカナや漢字になるのは通常である
- プレイヤーがカタカナで入力することはない。入力は必ずひらがな（および英字・数字・長音）
- 判定では表示用テキストを正規化し、入力と比較する（カタカナ → ひらがな、英字小文字、NFKC）

## 結果表示

- 次の問題へ進む前は、いかなる場合でも正解を表示する
- 一人の誤答: 問題文全文と正解を 3 秒表示
- 誰も押さない: 正解を表示してから次の問題へ（3 秒）
- 正解時: 従来どおり正解表示 3 秒

結果表示中は本文を出してよい。回答中は出さない。

## 誤答ロックアウト

- 対戦: 誤答したプレイヤーはその問題で再早押しできない
- 一人練習: ロックアウトを適用しない。誤答したらその問題を終了し、結果表示へ進む

## 長音

許可する。

## 時刻

端末間で比較できる共有タイムラインが必要。`performance.now()` 単体では足りない。

- ローカル高精度時計（`performance.now()`）と、オフセット付きの同期時刻を分離する
- ゲーム上の押下時刻・期限は同期時刻で持つ
- 一人練習ではオフセット 0（同一端末内）
- 対戦では NTP 風のプローブでオフセットを推定する（Phase 1 では推定関数と型まで実装し、シグナリングは後続）
